# 運用ガイド — 診察室オペレーション

このシステムは「説明が短くなる」ためのものではなく、
**同じ3〜5分で、患者さんの理解と行動が変わる**ことを狙っています。

---

## 1. 診察室の配置

```
        ┌─────────────┐
        │  説明用モニタ  │  ← 患者さんに正面から見える位置（21〜27インチ）
        └─────────────┘
             ↑ HDMI / ミラーリング
     ┌───────────────┐
     │ 診察用PC（電子カルテ） │
     └───────────────┘
        医師 ●        ● 患者さん
```

### 推奨する形

- **拡張ディスプレイ**：電子カルテは医師側の画面、説明画面は患者さん側のモニタに出す
- **タブレット**：患者さんの手元に渡して、指でスワイプしてもらう（説明後に読み返せる）
- モニタが1台しかない場合は、説明のときだけウィンドウを切り替える運用でも十分に機能します

### 医師用メモの扱い

各スライドの下に「医師向け：この画面で伝えること」が表示されます。
患者さんに画面を渡すときは、上部の **「🙈 医師メモを隠す」** をワンタップで非表示にできます。

---

## 2. スタッフの役割分担（効率化の要点）

説明のすべてを医師が行う必要はありません。

| 担当 | タイミング | 作業 |
| --- | --- | --- |
| **受付／看護師** | 診察前 | 「① 入力」で受付番号・年齢・性別・身長・体重・DXA結果を入力しておく |
| **看護師／PT** | 診察前 | ロコモ度テスト（立ち上がり・2ステップ）を実施し入力 |
| **医師** | 診察中 | 判定を確認 → 「② 説明」で図を見せながら説明 → 「③ 方針」で薬と運動を選ぶ |
| **看護師／PT** | 診察後 | 「④ 印刷」でパンフレットを印刷し、運動のやり方を実演して渡す |
| **医師** | 診察後 | 「⑤ 記録」でカルテ文をコピーして貼り付け |
| **医事** | 会計時 | 算定候補を確認（点数は院内で確認済みのものを使用） |

**入力が診察前に済んでいると、医師の作業は「確認 → 説明 → 選択」だけになります。**

---

## 3. 説明の型（骨粗鬆症・初回）

所要 3〜4分。スライド一覧から今日話す分だけ選べます。

| # | スライド | 話す内容 | 時間 |
| --- | --- | --- | --- |
| 1 | いまの骨の状態 | グラフの黒い点を指して「若い頃の◯%です」→「つまり、こういう状態です」と**必ず言い換える** | 40秒 |
| 2 | 骨粗鬆症とは | 「骨が減る」ではなく「**骨の中の柱が減る**」と説明。左右の図を比べる | 30秒 |
| 3 | 折れやすい4か所 | 既往のある部位が色づいている。「ここが折れましたね」 | 20秒 |
| 4 | 骨折の連鎖 | **ここが山場。**「今日の目的は痛みを取ることではなく、将来の骨折を防ぐことです」 | 50秒 |
| 5 | あなたの危険度 | 区分と根拠を示す。薬の必要性につなげる | 20秒 |
| 6 | 治療の3本柱 | 当院の運動療法を紹介。運動教室・個別リハビリの案内へ | 30秒 |
| 7 | あなたのお薬 | **一番大事な注意点1つだけ**を口頭で。残りはパンフレットにあると伝える | 40秒 |
| 8 | 運動処方 | 診察室で1回やってみせる。患者さんにも1回やってもらう | 40秒 |

### やってはいけないこと

- **全スライドを順に見せる** → 15枚あります。今日必要な6〜8枚に絞ってください
- **注意点を全部読み上げる** → パンフレットに印刷されています。口頭は1つに絞る
- **数値だけ伝える** → 「YAM 64%」だけでは行動は変わりません。必ず言い換えを添える

## 4. 説明の型（関節リウマチ・導入時）

| # | スライド | ポイント |
| --- | --- | --- |
| 1 | いまの炎症の強さ | **患者VASは必ず患者さん自身に指で示してもらう。** 医師の推測で入れると意味が薄れます |
| 2 | 関節の内張りが腫れる病気 | 「体質のせいでも、生活のせいでもありません」の一言を必ず添える |
| 3 | 関節はこの順にこわれる | 「一度こわれた関節は元に戻りません」→ 早期治療の根拠 |
| 4 | 最初の2年が勝負（発症2年以内のみ表示） | 治療強化のためらいを減らす |
| 5 | 目標と期限（T2T） | 「6か月で目標に届かなければ薬を見直す」と**先に伝えておく**。後の治療変更がスムーズになります |
| 6 | 治療の進め方 | 「薬が増える／変わるのは失敗ではなく、計画どおりの段階」 |
| 7 | MTXは週1回だけ | **連日服用の事故防止。曜日を具体的に指定し、ご家族にも同じ説明をする** |
| 8 | 費用の話 | 切り出しにくい話題なので**医療者側から必ず触れる**。高額療養費・付加給付・バイオシミラー |
| 9 | 運動は炎症の強さに合わせて | 「安静か運動か」の二択ではなく「時期に応じて内容を変える」 |

## 5. 説明の型（変形性膝関節症・ロコモ）

| # | スライド | ポイント |
| --- | --- | --- |
| 1 | あなたの膝 | レントゲンを見せながら。図は補助として使う |
| 2 | 歩く力の段階（ロコモ度） | 「今の痛み」ではなく「これからの生活の見通し」を語る指標 |
| 3 | 立ち上がりテストの結果 | **今の高さを覚えてもらう。**3か月後の再測定が最強の動機づけになります |
| 4 | 治療は下から順に | 「注射をしてほしい」への回答。注射だけでは筋力は増えません |
| 5 | 体重1kgで膝3kg | BMI 25以上のときだけ表示。数字で示すと納得されます |
| 6 | なぜ運動で痛みが軽くなるか | **効果が出るまで6〜8週かかると先に伝える。**途中脱落が減ります |
| 7 | 運動処方 | 診察室で実演 |

## 6. パンフレットの渡し方

印刷して「はい、どうぞ」で終わらせないための3つの動作。

1. **表紙の「今日決めたこと」を指さして読み上げる**（10秒）
   ここに今日の合意事項が箇条書きで入っています
2. **運動処方のページを開いて、1つ目の運動を実演する**（30秒）
   看護師・PTでも構いません
3. **運動記録表を見せて「次回持ってきてください」と言う**（10秒）
   持参率が上がり、次回の話が具体的になります

### 印刷するページの選び方

初回はフルセット、2回目以降は絞るのが実用的です。

| 場面 | 印刷するページ |
| --- | --- |
| 初回説明 | 全部（表紙・病気のしくみ・お薬・運動処方・記録表・食事・転倒予防・予定） |
| 薬の変更時 | 表紙・お薬・予定 |
| 運動の追加・変更時 | 表紙・運動処方・記録表 |
| 定期フォロー | 表紙・記録表・予定 |

高齢の方には、上部の「大きな文字」に切り替えてから印刷してください。

## 7. カルテ記載と算定

「⑤ 記録」画面で2種類のテキストが出ます。

| 種類 | 内容 | 使い分け |
| --- | --- | --- |
| **説明記録（詳細）** | 検査値・診断根拠・説明した内容・注意点・処方・運動処方・次回予定 | 初回説明、指導内容を残したいとき |
| **SOAP（簡潔）** | S/O/A/P の4行 | 定期再診 |

**S（患者さんの訴え）は手入力が必要です。** ほかは自動生成されます。

### 算定候補の使い方

- 表示されるのは「該当しうる項目の候補」です。**算定の可否を判断するものではありません**
- 点数は `src/data/fees.ts` の初期値で、**改定で変わります**。院内で確認した値に更新してください
- チェックした候補だけをコピーしてカルテに残せます

### 「今日のうちに済ませておきたいこと」

選んだ薬に応じて自動で出ます。見落としが致命的になる項目です。

- 骨吸収抑制薬 → **歯科受診の案内**（開始前の治療、以後3〜6か月ごとの口腔管理）
- 骨形成促進薬 → **終了時期の確認と後続薬の予約確保**（逐次療法の脱落は最も多い失敗）
- デノスマブ → **6か月後の予約**とCa/VitD製剤の継続確認
- MTX → **2〜4週ごとの血算・肝腎機能**

## 8. 継続のための院内の仕組み

骨粗鬆症治療の最大の課題は**治療継続率**です。システムだけでは解決しません。

- **骨粗鬆症マネージャー（日本骨粗鬆症学会認定）** を配置し、服薬状況と運動の継続を確認する
- **注射の予約は必ずその日に取る**（デノスマブ6か月、ゾレドロン酸1年は特に忘れられやすい）
- **運動記録表の持参**を毎回確認する（持ってきたことをまず褒める）
- **3か月後に立ち上がりテストを再測定**して、改善を数字で見せる
- 中断しそうな兆候（予約変更が続く、記録表を持ってこない）があれば、
  剤形の変更（週1回→月1回→年1回注射）を提案する。**続けられる薬がいちばん良い薬です**

## 9. よくあるつまずき

| 症状 | 原因と対処 |
| --- | --- |
| 印刷すると図の色が出ない | 印刷設定の「背景のグラフィック」がオフ。オンにして「規定として保存」 |
| パンフレットの枚数が多すぎる | 上部のページ選択で必要なものだけに絞る。両面印刷も可 |
| 図が小さくて患者さんが見えない | 上部の「文字 ＋」で拡大。設定画面で既定値を「大」にできる |
| 医療機関名が初期値のまま | ⚙️ 設定で入力し「保存する」。**端末ごとに必要**（構成A/B） |
| 前の患者さんの情報が残っている | 「⑤ 記録」の「診察を終了して次の患者さんへ」を押す |
| 骨密度を入れても判定が出ない | 単位（YAM% / Tスコア）の切り替えを確認。YAMは「64」、Tスコアは「-3.0」と入力 |
| QRコードが印刷されない | 設定の「患者向けページのURL」が空欄。入力すれば印刷されます |

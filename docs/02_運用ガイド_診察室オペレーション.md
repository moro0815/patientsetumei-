# 運用ガイド — 診察室オペレーション

このシステムは「説明が短くなる」ためのものではなく、
**同じ3〜5分で、患者さんの理解と行動が変わる**ことを狙っています。

---

## 1. 診察室の配置

```
        ┌─────────────┐
        │  説明用モニタ  │  ← 患者さんに正面から見える位置（21〜27インチ）
        └─────────────┘
             ↑ HDMI / ミラーリング
     ┌───────────────┐
     │ 診察用PC（電子カルテ） │
     └───────────────┘
        医師 ●        ● 患者さん
```

### 推奨する形

- **拡張ディスプレイ**：電子カルテは医師側の画面、説明画面は患者さん側のモニタに出す
- **タブレット**：患者さんの手元に渡して、指でスワイプしてもらう（説明後に読み返せる）
- モニタが1台しかない場合は、説明のときだけウィンドウを切り替える運用でも十分に機能します

### 医師用メモの扱い

各スライドの下に「医師向け：この画面で伝えること」が表示されます。
患者さんに画面を渡すときは、上部の **「🙈 医師メモを隠す」** をワンタップで非表示にできます。

---

## 2. スタッフの役割分担（効率化の要点）

説明のすべてを医師が行う必要はありません。

| 担当 | タイミング | 作業 |
| --- | --- | --- |
| **受付／看護師** | 診察前 | 「① 入力」で受付番号・年齢・性別・身長・体重・DXA結果を入力しておく |
| **看護師／PT** | 診察前 | ロコモ度テスト（立ち上がり・2ステップ）を実施し入力 |
| **医師** | 診察中 | 判定を確認 → 「② 説明」で図を見せながら説明 → 「③ 方針」で薬と運動を選ぶ |
| **看護師／PT** | 診察後 | 「④ 印刷」でパンフレットを印刷し、運動のやり方を実演して渡す |
| **医師** | 診察後 | 「⑤ 記録」でカルテ文をコピーして貼り付け |
| **医事** | 会計時 | 算定候補を確認（点数は院内で確認済みのものを使用） |

**入力が診察前に済んでいると、医師の作業は「確認 → 説明 → 選択」だけになります。**

### すでに問診システム・電子カルテに入力がある場合

再入力は不要です。次のどれかを使ってください。

| 状況 | 方法 | 手順 |
| --- | --- | --- |
| 院内のデジタル問診システムを使っている | **問診システムから読み込む** | 入力画面の「🔗 問診システムから読み込む」→ 当日の一覧から患者を選ぶ → 確認 → 取り込む |
| 問診システムの結果が画面に出ている | **貼り付け取り込み** | 結果を範囲選択してコピー → 入力画面の「貼り付けて取り込む」→ 貼る（自動で読み取ります）→ 確認 → 取り込む |
| カルテにYAM値が記載されている | **貼り付け取り込み** | 該当行をコピーして同様に貼り付け |
| 問診システムから CSV で出せる | **ファイル読み込み** | 取り込みパネルにドラッグ＆ドロップ |
| 問診システムにリンクを置ける | **URL連携** | 問診システム側に「せつめいナビを開く」ボタンを作る（URLの作り方は ⚙️ 設定 → 連携） |

読み取った内容は必ず確認画面に出ます。**誤読があればチェックを外してください。**

#### 関節リウマチの再診は手入力ゼロにできます

問診システムから読み込める内容と、貼り付けでしか取れない内容が分かれています。
**続けて2回行うと全部そろいます。**

| | 取り込める内容 |
| --- | --- |
| ① 🔗 問診システムから読み込む | 診察券番号・氏名・年齢・性別／患者全般評価VAS／mHAQ／朝のこわばり／前回との比較／患者さんの伝言／問診の警告 |
| ② 📋 スコアを貼り付ける | 腫脹・圧痛関節数／PGA・EGA／CRP・赤沈／SDAI・CDAI・DAS28-CRP・DAS28-ESR |

②は、問診システムの診察室画面（`doctor.html`）で関節所見を入力したあと
**「📋 スコアをカルテにコピー」**を押し、せつめいナビに貼るだけです。
①の取り込み完了画面に「続けてスコアを貼り付ける →」ボタンが出るので、そこから進めます。

所要は①②あわせて10秒ほどです。

> **DAS28-CRP の区分について**
> せつめいナビの既定は問診システムと同じ「慣用基準（2.6／3.2／5.1）」です。
> 両方の画面で同じ区分が出ます。変更するときは問診システム側も合わせてください。

**SDAI だけ分かっていて内訳が無い場合**も、そのまま説明を進められます。
入力画面の「問診システムで算出済みのスコア」欄に SDAI を入れれば、
メーターも治療目標の判定もその値で動きます。

内訳と算出済みスコアが両方ある場合は、本システムの計算値を優先し、
**食い違いがあれば「一致しません」と警告**します。転記ミスの発見に使ってください。

## 3. 説明の型（骨粗鬆症・初回）

所要 3〜4分。スライド一覧から今日話す分だけ選べます。

| # | スライド | 話す内容 | 時間 |
| --- | --- | --- | --- |
| 1 | いまの骨の状態 | グラフの黒い点を指して「若い頃の◯%です」→「つまり、こういう状態です」と**必ず言い換える** | 40秒 |
| 2 | 骨粗鬆症とは | 「骨が減る」ではなく「**骨の中の柱が減る**」と説明。左右の図を比べる | 30秒 |
| 3 | 折れやすい4か所 | 既往のある部位が色づいている。「ここが折れましたね」 | 20秒 |
| 4 | 骨折の連鎖 | **ここが山場。**「今日の目的は痛みを取ることではなく、将来の骨折を防ぐことです」 | 50秒 |
| 5 | あなたの危険度 | 区分と根拠を示す。薬の必要性につなげる | 20秒 |
| 6 | 治療の3本柱 | 当院の運動療法を紹介。運動教室・個別リハビリの案内へ | 30秒 |
| 7 | あなたのお薬 | **一番大事な注意点1つだけ**を口頭で。残りはパンフレットにあると伝える | 40秒 |
| 8 | 運動処方 | 診察室で1回やってみせる。患者さんにも1回やってもらう | 40秒 |

### やってはいけないこと

- **全スライドを順に見せる** → 15枚あります。今日必要な6〜8枚に絞ってください
- **注意点を全部読み上げる** → パンフレットに印刷されています。口頭は1つに絞る
- **数値だけ伝える** → 「YAM 64%」だけでは行動は変わりません。必ず言い換えを添える

## 6. 説明の型（症状別疾患：腰・首・肩・肘・指・股・足・外傷）

所要 4〜6分。13疾患すべて同じ流れです。**手順を覚えるのは1回で済みます。**

```
① 現状          「今日わかったこと」を1枚で（痛む場所の図・痛みの強さ）
        ↓
② 病気のしくみ  「体の中で何が起きているか」「なぜ痛いか」を図で
        ↓
③ 見通し        「いつ治るか」を時間軸の図で ← ここがいちばん大事
        ↓
④ 治療          「治療は下の段から積み上げます」＋いま提案する段
        ↓
⑤ 運動療法      なぜ効くか → あなたの運動（図つき）
        ↓
⑥ 生活          やってみること／避けること／すぐ受診が必要なサイン
```

### なぜ「見通し」を治療より先に置いているか

外来で患者さんがいちばん知りたいのは「**これはいつ治るのか**」です。
ここに答えが返ってこないと不安が残り、治療の説明が頭に入りません。
先に見通しを共有してから治療を説明すると、納得度が大きく変わります。

数字は必ず口に出してください。

| 疾患 | 伝える数字の例 |
| --- | --- |
| 腰椎椎間板ヘルニア | 「約8割の方が3か月ほどで日常生活に支障のない状態になります」 |
| 肩関節周囲炎 | 「炎症期→拘縮期→回復期をたどって、多くは1〜2年で自然に良くなります」 |
| テニス肘 | 「1年以内に8〜9割の方が良くなります。ただし運動の効果が出るまで6〜12週かかります」 |
| 足底腱膜炎 | 「8〜9割の方が保存療法で良くなりますが、数か月〜1年かかります」 |
| 足関節捻挫 | 「Ⅰ度なら1〜2週、Ⅱ度で3〜6週。ただし3〜4割の方がくり返します」 |
| 肉離れ | 「Ⅱ度で3〜6週。急いで復帰すると必ずと言っていいほど再発します」 |
| シンスプリント | 「早い段階なら2〜4週で軽くなります。完全に休む必要はなく、水泳や自転車に切り替えます」 |

### レッドフラッグは必ず1回は口に出す

入力画面の「見落としてはいけない所見」で選んだ内容は、
判定パネルに警告として出て、カルテ記載文にも残ります。
**選んでいなくても、パンフレットの「すぐご連絡ください」欄には必ず印刷されます。**

とくに次の3つは、患者さんの言葉で伝えてください。

- 腰・背中：「**おしっこが出にくい・もれる、おしりのまわりがしびれる**」→ 待たずに受診
- 首：「**歩きにくい、ボタンがかけにくい**」→ 待たずに受診
- けが：「**まったく体重をかけられない、足先が冷たい・しびれる**」→ すぐ受診

### 部位から探す

トップ画面は、**最上段が骨粗鬆症と関節リウマチ**、その下が**部位ごと**のまとまりです。
変形性膝関節症・ロコモは「股・膝」にあります（変形性股関節症の隣）。
病名が思い出せないときは、**検索欄に患者さんの言い方を入れてください**。

- 「五十肩」→ 肩関節周囲炎
- 「ばね指」→ 狭窄性腱鞘炎
- 「ケルバン」「手首の腱鞘炎」「産後の手首の痛み」→ ドケルバン腱鞘炎
- 「ヘルニア」→ 腰椎椎間板ヘルニア
- 「かかと」→ 足底腱膜炎
- 「ねんざ」→ 足関節外側側副靱帯損傷
- 「すね」→ シンスプリント
- 「ひざ」「ロコモ」→ 変形性膝関節症・ロコモ（**「股・膝」のところにあります**）

### 運動処方は「おすすめの組み合わせ」から

「③ 方針」の運動療法で、疾患ごとの推奨セットがボタンになっています。
病期のあるもの（肩関節周囲炎・椎間板ヘルニア・圧迫骨折・捻挫・肉離れ）は、
**時期ごとにセットが分かれています。時期を間違えると悪化するため、必ず選び分けてください。**

| 取り違えやすい組み合わせ | 注意 |
| --- | --- |
| 腰部脊柱管狭窄症 と 腰椎椎間板ヘルニア | 狭窄症は**腰を丸める**方向、ヘルニアは**反らす**方向が効くことが多く、処方が逆になります |
| 肩関節周囲炎の炎症期 と 拘縮期 | 炎症期に強いストレッチを指示すると悪化します。炎症期は振り子運動まで |
| 脊椎圧迫骨折 | 前屈・回旋を伴う運動（腹筋運動・前屈）は**禁忌**です |
| 肉離れの急性期 | ストレッチは**行いません**。痛みが引いてから始めます |
| シンスプリント と 脛骨疲労骨折 | **圧痛が5cm以上に広がるか、一点かで区別**します。一点なら画像で確認し、休む期間が大きく変わります |

## 7. パンフレットの渡し方

印刷して「はい、どうぞ」で終わらせないための3つの動作。

1. **表紙の「今日決めたこと」を指さして読み上げる**（10秒）
   ここに今日の合意事項が箇条書きで入っています
2. **運動処方のページを開いて、1つ目の運動を実演する**（30秒）
   看護師・PTでも構いません
3. **運動記録表を見せて「次回持ってきてください」と言う**（10秒）
   持参率が上がり、次回の話が具体的になります

### 印刷するページの選び方

初回はフルセット、2回目以降は絞るのが実用的です。

| 場面 | 印刷するページ |
| --- | --- |
| 初回説明 | 全部（表紙・病気のしくみ・お薬・運動処方・記録表・食事・転倒予防・予定） |
| 薬の変更時 | 表紙・お薬・予定 |
| 運動の追加・変更時 | 表紙・運動処方・記録表 |
| 定期フォロー | 表紙・記録表・予定 |

高齢の方には、上部の「大きな文字」に切り替えてから印刷してください。

## 8. カルテ記載と算定

「⑤ 記録」画面で2種類のテキストが出ます。

| 種類 | 内容 | 使い分け |
| --- | --- | --- |
| **説明記録（詳細）** | 検査値・診断根拠・説明した内容・注意点・処方・運動処方・次回予定 | 初回説明、指導内容を残したいとき |
| **SOAP** | S/O/A/P の4行 | 定期再診 |
| **1〜2行（経過欄用）** | `[RA] SDAI 20.2(中疾患活動性) / TJC6/SJC4 / CRP 1.2 → Rp:MTX / 次回:3か月後` | 経過欄が狭いカルテ、フォロー時 |

**S（患者さんの訴え）は手入力が必要です。** ほかは自動生成されます。

### 部分コピー

必要な部分だけを取り出せます。カルテの欄が分かれている場合に便利です。

| ボタン | 内容 | 貼る先の例 |
| --- | --- | --- |
| 検査値の1行まとめ | その日の検査値を1行に | 経過表・サマリ |
| 運動処方 | 処方した運動と回数・頻度 | リハビリ指示、スタッフへの申し送り |
| 説明した内容のみ | 説明項目の箇条書き | 指導内容の記載欄 |
| チェックした算定候補 | 選んだ算定項目 | 医事への申し送り |

コピーボタンは押すと「✓ コピーしました」に変わります。
確認ダイアログは出ないので、診察の流れが止まりません。

### 算定候補の使い方

- 表示されるのは「該当しうる項目の候補」です。**算定の可否を判断するものではありません**
- 点数は `src/data/fees.ts` の初期値で、**改定で変わります**。院内で確認した値に更新してください
- チェックした候補だけをコピーしてカルテに残せます

### 「今日のうちに済ませておきたいこと」

選んだ薬に応じて自動で出ます。見落としが致命的になる項目です。

- 骨吸収抑制薬 → **歯科受診の案内**（開始前の治療、以後3〜6か月ごとの口腔管理）
- 骨形成促進薬 → **終了時期の確認と後続薬の予約確保**（逐次療法の脱落は最も多い失敗）
- デノスマブ → **6か月後の予約**とCa/VitD製剤の継続確認
- MTX → **2〜4週ごとの血算・肝腎機能**

## 9. 継続のための院内の仕組み

骨粗鬆症治療の最大の課題は**治療継続率**です。システムだけでは解決しません。

- **骨粗鬆症マネージャー（日本骨粗鬆症学会認定）** を配置し、服薬状況と運動の継続を確認する
- **注射の予約は必ずその日に取る**（デノスマブ6か月、ゾレドロン酸1年は特に忘れられやすい）
- **運動記録表の持参**を毎回確認する（持ってきたことをまず褒める）
- **3か月後に立ち上がりテストを再測定**して、改善を数字で見せる
- 中断しそうな兆候（予約変更が続く、記録表を持ってこない）があれば、
  剤形の変更（週1回→月1回→年1回注射）を提案する。**続けられる薬がいちばん良い薬です**

## 10. よくあるつまずき

| 症状 | 原因と対処 |
| --- | --- |
| 印刷すると図の色が出ない | 印刷設定の「背景のグラフィック」がオフ。オンにして「規定として保存」 |
| パンフレットの枚数が多すぎる | 上部のページ選択で必要なものだけに絞る。両面印刷も可 |
| 図が小さくて患者さんが見えない | 上部の「文字 ＋」で拡大。設定画面で既定値を「大」にできる |
| 医療機関名が初期値のまま | ⚙️ 設定で入力し「保存する」。**端末ごとに必要**（構成A/B/C） |
| 前の患者さんの情報が残っている | 「⑤ 記録」の「診察を終了して次の患者さんへ」を押す |
| 骨密度を入れても判定が出ない | 単位（YAM% / Tスコア）の切り替えを確認。YAMは「64」、Tスコアは「-3.0」と入力 |
| QRコードが印刷されない | 設定の「患者向けページのURL」が空欄。入力すれば印刷されます |
| 貼り付けても何も読み取れない | 「項目名」と「数値」が同じ行にあるか確認。表形式で改行が入っていると読めないことがあります。読めない書式があれば項目名を教えてください（パーサーに追加できます） |
| 患者VASと医師VASが入れ替わって取り込まれた | 元の表記を確認してください。「患者VAS」「医師VAS」など、どちらか分かる語が必要です |
| CRPの警告が出る | mg/L で記載されている可能性があります。本システムは mg/dL で扱います |
| SDAIが「一致しません」と警告される | 内訳から計算した値と食い違っています。転記ミスか、VASの単位（cm/mm）の違いが原因のことが多いです |
| 「問診システムに接続できませんでした」 | 問診システムが起動しているか確認。急ぐときは貼り付け取り込みで進められます（内容は同じです） |
| 問診の一覧が空になる | 当日の問診がまだない状態です。検索欄（氏名・カナ・診察券番号・生年月日）から過去分を探せます |
| 問診システムとせつめいナビでDAS28-CRPの区分が違う | 設定 →「臨床判断の基準」で使うカットオフを確認。既定は問診システムと同じ「慣用基準」です |

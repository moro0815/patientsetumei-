## 骨粗鬆症

### 典拠

- **骨粗鬆症の予防と治療ガイドライン 2025年版**
  （日本骨粗鬆症学会／日本骨代謝学会／骨粗鬆症財団、2025年8月公表・9月発行）
  2015年版から10年ぶりの全面改訂。Tスコア評価の正式併用、
  ASBMR/NOF 2024の初期治療アルゴリズムの収載、ゾレドロン酸・アバロパラチド・ロモソズマブの追加。
- **原発性骨粗鬆症の診断基準**（2012年度改訂版、上記ガイドラインに収載）
- **日本版 二次性骨折予防のための骨折リエゾンサービス（FLS）クリニカルスタンダード**（日本骨粗鬆症学会、2019）
- **薬剤関連顎骨壊死の病態と管理：顎骨壊死検討委員会ポジションペーパー2023**

| 抜歯時の骨吸収抑制薬 | **原則休薬しない**（ポジションペーパー2023） | `src/data/drugs.ts`／`src/components/figures/lifestyle.tsx` |
| 身長低下 | 4cm以上で椎体骨折を疑い胸腰椎X線を検討 | `src/logic/osteoporosis.ts` |

### 実装上の注意

- **YAM(%) と Tスコアの換算**は、変動係数（SD/若年成人平均値）を腰椎12%・大腿骨13%として計算しています
  （YAM 70% ≒ T −2.5、YAM 80% ≒ T −1.7 という国内で慣用されている対応と整合）。
  機種・部位・参照データベースで差があるため、**DXA報告書にTスコアがある場合はそちらを優先**してください。
  → `src/logic/osteoporosis.ts` の `YAM_CV`
- **FRAX® の計算は実装していません。** DXA装置または FRAX® 公式サイトで算出した値を入力してください。
- **ステロイド性骨粗鬆症**は別の管理指針（スコア）で判断します。
  ステロイド使用にチェックすると画面に注意が表示されます。
- 骨折リスク層別化は ASBMR/NOF 2024 の考え方に沿った**参考区分**です。最終判断は医師が行ってください。

## 関節リウマチ

### 典拠

- **関節リウマチ診療ガイドライン 2024改訂**（一般社団法人 日本リウマチ学会、2024年5月発行、72CQ）
  MTX皮下注を薬物治療アルゴリズムに追加、JAK阻害薬とbDMARDを分けて記載しbDMARDの使用を優先、
  ライフステージ別（高齢者・妊娠授乳期）のCQを新設。
- **2010 ACR/EULAR classification criteria for RA**（Ann Rheum Dis 2010;69:1580-8）
- **ACR/EULAR provisional definition of remission in RA**（Ann Rheum Dis 2011;70:404-13）
- **Treating rheumatoid arthritis to target: 2014 update**（Ann Rheum Dis 2016;75:3-15）

### 実装した計算式と基準

| 指標 | 式 | 区分 |
| --- | --- | --- |
| DAS28-ESR | 0.56√TJC28 + 0.28√SJC28 + 0.70 ln(ESR) + 0.014×GH(0-100mm) | 寛解 <2.6／低 ≦3.2／中 ≦5.1／高 >5.1 |
| DAS28-CRP | 0.56√TJC28 + 0.28√SJC28 + 0.36 ln(CRP[mg/L]+1) + 0.014×GH(0-100mm) + 0.96 | 寛解 <2.3／低 <2.7／中 ≦4.1／高 >4.1 |
| SDAI | SJC28 + TJC28 + 患者VAS(0-10) + 医師VAS(0-10) + CRP(mg/dL) | 寛解 ≦3.3／低 ≦11／中 ≦26／高 >26 |
| CDAI | SJC28 + TJC28 + 患者VAS(0-10) + 医師VAS(0-10) | 寛解 ≦2.8／低 ≦10／中 ≦22／高 >22 |
| Boolean寛解 | TJC≦1 かつ SJC≦1 かつ CRP≦1mg/dL かつ 患者VAS≦1 | 全て満たせば寛解 |

**単位の扱い（重要）**
- CRP は日本の検査室表記に合わせて **mg/dL で入力**します。DAS28-CRP の原式は mg/L のため、内部で10倍して計算します。
- 全般評価 VAS は **0〜10 cm で入力**します。DAS28 の原式は 0〜100 mm のため、内部で10倍します。
- ESR は ln(0) を避けるため下限を 2 mm/h として扱います。

→ 実装とテスト：`src/logic/ra.ts`／`src/logic/ra.test.ts`

### ACR/EULAR 2010 分類基準（参考スコア）

| 項目 | 配点 |
| --- | --- |
| A. 罹患関節：大関節1／大関節2-10／小関節1-3／小関節4-10／10か所超（小関節を1つ以上含む） | 0／1／2／3／5 |
| B. 血清学的検査：陰性／低値陽性／高値陽性（基準上限の3倍超） | 0／2／3 |
| C. 急性期反応物質：正常／CRPまたはESRが異常 | 0／1 |
| D. 滑膜炎の持続期間：6週未満／6週以上 | 0／1 |

**合計6点以上でRAと分類。** これは分類基準であり診断基準ではありません。確定診断は医師が総合的に行います。

基準値は RF 15 IU/mL・抗CCP 4.5 U/mL を上限として計算しています。
**施設の検査値上限に合わせて確認してください**（`src/logic/ra.ts` の `classification2010`）。

### 治療アルゴリズム（患者説明用に簡略化）

| フェーズ | 内容 |
| --- | --- |
| I | MTX 第一選択（経口／皮下注のいずれも選択可。皮下注は2022年保険適用） |
| II | MTX効果不十分 → csDMARD追加、または bDMARD／JAK阻害薬を追加（**bDMARDの使用を優先**） |
| III | 効果不十分・副作用 → 別の bDMARD／JAK阻害薬へ変更 |

T2T：3か月ごとに評価し、6か月で目標（寛解または低疾患活動性）未達なら治療を調整。

## 変形性膝関節症・ロコモ

### 典拠

- **変形性膝関節症診療ガイドライン 2023**（日本整形外科学会）
- **OARSI guidelines for the non-surgical management of knee osteoarthritis**（2019）
- **ロコモ度テストの臨床判断値**（日本整形外科学会。2015年にロコモ度1・2、2020年にロコモ度3を追加）

### 実装した基準

| 項目 | 基準 |
| --- | --- |
| ロコモ度1 | 片脚で40cmの台から立てない／2ステップ値 1.3未満／ロコモ25 7点以上 |
| ロコモ度2 | 両脚で20cmの台から立てない／2ステップ値 1.1未満／ロコモ25 16点以上 |
| ロコモ度3 | 両脚で30cmの台から立てない／2ステップ値 0.9未満／ロコモ25 24点以上 |
| 判定方法 | 3つのテストのうち**最も移動機能低下が進行している段階**を採用 |
| 2ステップ値 | 2歩幅(cm) ÷ 身長(cm) |
| Kellgren-Lawrence | グレード0〜4 |
| 膝への負荷 | 平地歩行で体重の約3倍、階段昇降で約5倍 |
| 運動療法 | 有酸素運動・筋力強化訓練・関節可動域訓練を推奨（推奨度A相当）。減量と併せて保存療法の中心 |

→ 実装とテスト：`src/logic/locomo.ts`／`src/logic/locomo.test.ts`

**立ち上がりテストの実装上の注意**：
「40cmでも立てない（`'cannot'`）」と「未実施（`null`）」を型で明確に区別しています。
この2つを混同すると判定が真逆になるため、入力画面でも別のボタンに分けています。

### 実装した判断（`src/logic/condition.ts`）

| 判断 | 内容 |
| --- | --- |
| レッドフラッグ | 疾患モデルの `redFlagOptions` を機械的に拾い、1つでも該当すれば警告と紹介提案を出す。ロジックに病名は書かない |
| 治療の段の提案 | すでに受けた治療のうち最も上の段の「次」を提案。長引いている場合・痛みが強い場合は土台だけで様子を見ず薬の段へ |
| 経過フェーズ | 発症からの期間から、回復の時間軸の「いまここ」を推定 |
| 痛みの区分 | NRS 0＝なし、1〜3＝軽い、4〜6＝中くらい、7〜10＝強い |

**診断そのものは行いません。** 判断するのは「見落としてはいけないものを拾うこと」と
「治療の段を提案すること」の2つだけです。

### とくに注意して記述した点

| 疾患 | 注意点 |
| --- | --- |
| 腰部脊柱管狭窄症 | 屈曲位で症状が軽減する特性を利用し、運動は**屈曲方向**が中心。椎間板ヘルニアとは処方が逆になるため取り違えに注意 |
| 腰椎椎間板ヘルニア | 症状の centralization / peripheralization を患者さん自身が判断できるよう明記。安静臥床の長期化は有害 |
| 頚椎症性神経根症 | 脊髄症（巧緻運動障害・歩行障害）の所見を毎回確認するよう、症状・所見・レッドフラッグの3か所に配置 |
| 脊椎圧迫骨折 | 体幹の**屈曲・回旋を伴う運動は禁忌**。急性期は下肢の運動から始める |
| 上腕骨外側上顆炎 | ステロイド局注の中長期予後がむしろ不良との報告を明記し、適応を絞る記述にした |
| 足底腱膜炎 | 踵骨棘は無症候例にも高頻度であり、痛みの原因と断定しないよう明記 |
| 足関節捻挫 | Ottawa ankle rules を所見の選択肢としてそのまま実装。成長期の骨端線損傷にも言及 |
| 肉離れ | 急性期のストレッチは禁忌。復帰は「痛みが消えた」ではなく「力が戻った」で判断 |
| ばね指 | 朝に強く日中軽快するパターンは関節リウマチと紛らわしいため、他関節腫脹の確認をレッドフラッグに配置 |

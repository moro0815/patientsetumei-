# レントゲンから骨の図を作る

骨の形は、生成AIにも私（Claude）にも**記憶から描き起こすことができません**。
座標を推測することになるため、それらしくはなっても正しくなりません。
実際に大腿骨遠位部で試し、形態図として使えないと判断しました。

一方、**レントゲン画像から輪郭をトレースすれば、形の正しさは構造的に保証されます**。
推測が一切入らず、費用もかかりません。この文書はその手順です。

---

## 1. なぜこの方法がいちばん確実か

| 方法 | 形の正しさ | 費用 | 権利 |
| --- | --- | --- | --- |
| **レントゲンをトレース** | **撮影像そのものなので正しい** | 0円 | 自院の画像 |
| Servier Medical Art | 専門家が作成しており高い | 0円 | CC BY 4.0（表示が必要） |
| イラストレーターへ発注 | 最も高い | 12〜13点で数万円〜 | 買い切り |
| 生成AI・私が描く | **低い（推測になる）** | 0円 | — |

## 2. お渡しいただくもの

### 必要な画像

| 部位 | 撮影方向 | 用途 |
| --- | --- | --- |
| 膝 | 正面（立位が望ましい） | 変形性膝関節症・軟骨のすり減り |
| 肩 | 正面 | 肩関節周囲炎・関節包の拘縮 |
| 股関節 | 正面 | 変形性股関節症 |
| 腰椎 | 側面 | 脊柱管狭窄症・椎間板ヘルニア・圧迫骨折 |
| 頚椎 | 側面・斜位 | 頚椎症性神経根症 |
| 手 | 正面 | 関節リウマチ・ばね指・ドケルバン腱鞘炎 |
| 足 | 側面（荷重位） | 足底腱膜炎 |
| 足関節 | 正面 | 足関節外側側副靱帯損傷 |

**「正常」または「軽度」の像**をお願いします。
病変は入力に応じてコード側で描き加えるため、下地は正常な形が望ましいです。

### 患者情報の扱い

**画像に写り込む患者情報を、渡す前に必ず消してください。**

- 氏名・カルテID・生年月日・撮影日時・施設名（画像の四隅と焼き込み文字）
- DICOM ではなく、**PNG または JPEG に書き出したもの**をお願いします
  （DICOM のタグに患者情報が残るため）
- 画面のスクリーンショットで構いません。解像度は長辺 1200px 程度あれば十分です

**患者さんご本人の画像を使うことに懸念がある場合の代替**

- 骨模型（実物大の教育用模型）の写真 — これでも輪郭は正確です
- 教育用ファントムの撮影像
- 学会・教科書の**図をトレースすることはできません**（著作権）。
  ただし「骨模型を自分で撮った写真」は問題ありません

### 置き場所

```
deploy/figure-assets/
├── xray/                    ← ここに置いてください
│   ├── knee-ap.png
│   ├── shoulder-ap.png
│   └── lumbar-lateral.png
└── レントゲンから骨の図を作る手順.md（このファイル）
```

`xray/` は `.gitignore` に入れてあり、**リポジトリには入りません**。
トレース後の座標（SVGパス）だけがコードに入り、元画像は納品物に含まれません。

---

## 3. こちらで行う作業

1. 画像から骨の輪郭を拾い、ベクター（SVGパス）にする
2. `viewBox` をそろえ、部品ごとに分ける
   - 例（膝）：大腿骨 / 脛骨 / 腓骨 / 膝蓋骨 / 内側の軟骨 / 外側の軟骨
3. 患者データで変わる部分をコードで載せる
   - 内側だけすり減る／病期で関節のすき間が狭くなる／左右が入れ替わる
4. 指した所の色が変わるようにする（`figures/connected.tsx` に追加）
5. 配色をシステムのパレットにそろえ、日本語ラベルを載せる
6. A4印刷での見え方を確認する
7. **先生に形の妥当性を確認していただく**（ここは必ずお願いします）

---

## 4. 出典の表記について

自院のレントゲンをトレースしたものは、**外部への表示義務はありません**。
ただし資料集の「出典一覧」には、下記のように記載しておきます。

```
骨格の輪郭は当院で撮影した単純X線像をもとに作図（患者情報は含まれません）
```

Servier Medical Art を併用する場合は、CC BY 4.0 の表示が必要です。
その場合はパンフレット下部に1行入れます（`差し替えの手引き.md` に記載）。

---

## 5. 形態図が要らない図について

93点のうち、骨の形の正しさが要るのは**12〜13点だけ**です。
残りは概念図（治療の階段・回復の見通し・疾患活動性メーター・体の地図など）で、
手描きの模式図のままで問題ありません。むしろ要素が少ないほうが伝わります。

**まず膝と肩の2点だけ**お渡しいただければ、仕上がりを見て
残りを進めるかご判断いただけます。

# 図をプロのイラストに差し替える

いま収録している病態図はすべて手描きのSVG（模式図）です。
**解剖の静止画だけ**を、プロが描いた素材に差し替えると、見た目が大きく改善します。

このフォルダは、その素材を置く場所と、差し替えの手順をまとめたものです。

---

## 1. どの図が差し替えられるか

図には2種類あり、**差し替えられるのは片方だけ**です。

### 差し替えできない図（患者さんのデータが載るもの）

数値・重症度・左右・「いまここ」が入力に応じて変わります。
画像素材では置き換えられません。改善するとしたら、線と配色の作り込みになります。

骨密度グラフ／骨梁／疾患活動性メーター／罹患関節マップ／骨折リスク区分／
脊柱管の狭窄度／ヘルニアの左右／股関節の病期／股関節にかかる力／肩の可動域／
肩の3つの時期／圧迫骨折の数／ばね指・ねんざ・肉離れの段階／痛みのNRS／
体の地図／治療の階段／回復の時間軸／立ち上がりテスト／ロコモ度／体重と膝の負担

### 差し替えできる図（静止した解剖図）

## 2. どこから素材を入手するか

### Servier Medical Art（推奨・無料・商用可）

- <https://smart.servier.com/>
- ライセンス：**CC BY 4.0**（表示さえすれば、商用利用・改変・再配布が可能）
- 形式：SVG / PowerPoint。**SVGを選んでください**（拡大・印刷で劣化しません）
- 数千点の医療イラストがあり、運動器の解剖も収録されています

### そのほかの選択肢

| 入手先 | ライセンス | 備考 |
| --- | --- | --- |
| BioRender | 有料（サブスク） | 品質は高いが、出力の再配布条件を要確認 |
| 医療イラストレーターへの発注 | 買い切り | いちばん質が高い。10〜15点で数万円〜 |

## 3. 素材を渡していただくときのお願い

このフォルダ（`deploy/figure-assets/`）に、次の形で置いてください。

```
deploy/figure-assets/
├── README.md          （このファイル）
├── LICENSE.txt        ← 素材のライセンス条文をそのまま保存
└── svg/
    ├── shoulder-joint.svg
    ├── elbow-lateral.svg
    ├── hand-tendon.svg
    └── ...
```

**素材を選ぶときの条件**

1. **SVG形式**であること（PNG/JPEGは印刷で劣化し、ファイルも重くなります）
2. **文字が入っていない**こと。日本語ラベルはコード側で載せるためです
   （文字入りしかない場合はそのままでも構いません。こちらで消します）
3. 向き・断面が上の表に合っていること
4. ライセンスが**商用利用・改変を許している**こと

---

## 4. こちらで行う作業

素材をいただいたら、次を行います。

1. SVGの最適化（不要なメタデータ・IDの削除、パスの整理）
2. 配色をシステムのパレット（`figures/common.tsx` の `PALETTE`）に合わせる
3. 日本語ラベル・矢印・強調（痛む場所の印など）をコード側で重ねる
4. **患者データが載る部分は、素材の上にコードで描き足す**
   （例：椎間板ヘルニアなら、素材の椎間板の上に「飛び出した髄核」を左右反転できる形で重ねる）
5. 出典表記の追加
   - 資料集の「出典一覧」に1件
   - パンフレット下部に1行
   - 例：`イラストの一部に Servier Medical Art（CC BY 4.0）を改変して使用`
6. A4印刷での見え方の確認、ファイルサイズの確認

## 5. 差し替えないという判断もあります

模式図には、写実的な解剖図にはない利点があります。

- **要素が少ないぶん、伝えたい1点に目が行く**
- 実際の解剖より単純なので、高齢の患者さんにも読みやすい
- 患者さんのデータを載せられる

写実的な図が向くのは、**「体の中がどうなっているか」を知りたい患者さん**です。
一方、**「で、どうすればいいのか」を知りたい患者さん**には模式図のほうが伝わります。

実際の診察で使ってみて、「この図は伝わらない」というものだけを差し替えるのが、
いちばん無駄がありません。**まず数週間お使いいただき、伝わらなかった図を教えてください。**

## 6. 運動の図の配色ルール

運動の図では「いまの姿勢」と「目指す姿勢」が同じ絵に並びます。
色が図ごとに違うと、患者さんは毎回どちらが目標なのかを読み直すことになるため、
意味ごとに色を固定しています（`figures/common.tsx` の `MOTION`）。

| 意味 | 色 | 線 |
| --- | --- | --- |
| 開始姿勢（動く前） | 薄いグレー `#b6bfc9` | 破線 |
| 終了姿勢（目標の形） | 濃い紺 `#16283d` | 実線 |
| 動作の向き・その説明 | 青 `#2f7fb0` | 実線＋矢印 |
| 注意点・やってはいけないこと | オレンジ `#cf5a20` | 実線 |
| 支持物（机・壁・床・マット） | グレー `#9aa5b1` | 実線 |

白黒で印刷しても開始と終了が区別できるよう、**開始姿勢は必ず破線**にします。

色を変えるときは `MOTION` の値を1か所だけ直してください。
なお既存37点のうち、このルールに揃えたのはまだ一部です（下記4点の改修時に適用）。
残りは診察で使いながら順に揃えていきます。
